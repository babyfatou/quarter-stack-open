# QSO Practice Project

## About the Project

This is a practice website created to learn how to start a web development project, organize files, and use Git and GitHub.

## Files and Folders

- `index.html` — The home page of the website.
- `about.html` — Information about the student and educational goals.
- `projects.html` — Projects and skills being learned.
- `contact.html` — A page for contact information.
- `images/` — Stores images used on the website.
- `css/` — Stores CSS files for styling the website.
- `js/` — Stores JavaScript files for interactive features.
